# BDU

Aplicativo mobile acadêmico para integrar a relação entre alunos e biblioteca universitária.

## Objetivo

Facilitar a interação dos alunos com a biblioteca, tornando atividades como aluguel de livros, pesquisa no acervo, consulta de disponibilidade, lista de espera, lista de desejos e pagamento de multas mais simples e acessíveis pelo aplicativo.

## Tecnologias

* Kotlin
* Jetpack Compose
* Android Studio
* Supabase
* API
* Banco de dados
* Retrofit
* Coil
* Coroutines
* Navigation Compose

## Funcionalidades

* Sistema de aluguel de livros
* Sistema de busca com filtros
* Consulta de disponibilidade dos livros
* Lista de espera
* Lista de desejos
* Pagamento de multas
* Integração com API
* Integração com Supabase
* Banco de dados para armazenamento das informações

## Status do projeto

Em desenvolvimento / Acadêmico.

## Aprendizados

Durante o desenvolvimento do BDU, foram aplicados conceitos de desenvolvimento mobile com Kotlin, criação de interfaces modernas com Jetpack Compose, integração com API, utilização do Supabase, conexão com banco de dados, organização de telas, navegação entre páginas e desenvolvimento de uma solução voltada para o ambiente universitário.

## Como executar o projeto

O BDU é um aplicativo Android desenvolvido no Android Studio.

### Passo a passo

Clone o repositório do projeto:

```bash
git clone https://github.com/LucasLimadeSousa/BDU.git
```

Abra o projeto no Android Studio.

Configure as informações necessárias para funcionamento do app, como:

* Chave da API
* Configuração do Supabase
* Banco de dados
* URL da API

Depois disso, sincronize o Gradle e execute o projeto em um emulador Android ou dispositivo físico.

## Observações

O projeto utiliza API, Supabase e banco de dados, portanto algumas funcionalidades dependem de configurações privadas.

As chaves de API e credenciais do banco não devem ser expostas publicamente no repositório.

Para executar corretamente, é necessário configurar o ambiente de desenvolvimento e as credenciais utilizadas pelo sistema.

## Sobre o app

BDU é um aplicativo acadêmico desenvolvido para facilitar a relação entre alunos e biblioteca universitária.

A proposta do app é modernizar os serviços da biblioteca, permitindo que os alunos pesquisem livros, verifiquem disponibilidade, realizem aluguéis, entrem em listas de espera, salvem livros em uma lista de desejos e realizem o pagamento de multas de forma mais prática.
